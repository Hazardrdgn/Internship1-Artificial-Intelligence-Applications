\# Titanic Survival Prediction Model



This project was developed during my mandatory Artificial Intelligence Internship (July 06 - August 01, 2026). It aims to predict the survival of Titanic passengers using machine learning techniques.



\## Workflow \& Data Processing

\* \*\*Data Cleaning:\*\* Handled missing values (filled `Age` with median and `Embarked` with mode).

\* \*\*Feature Engineering:\*\* Applied One-Hot Encoding for categorical variables.

\* \*\*Algorithm:\*\* Random Forest Classifier.

\* \*\*Model Accuracy:\*\* 79.89%



\## Technologies Used

\* Python, Pandas, Scikit-Learn
